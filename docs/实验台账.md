# 实验台账

每次运行都在这里记录配置、结果与产物路径，供论文实验章节核对。实验编号见[分周排期](02_学习与实验计划_按周排期.md)。

## 填写规则

- 一行 = 一次 run（一个 `results/runs/<run_id>/`）
- 记录题目划分、切分策略及窗口和重叠、检索类型、top-k、重排序方法、上下文预算、生成模型与提示词、评判器版本、阈值来源、运行硬件和并发。
- 按题记录证据 ID、首轮及最终答案、三个分项与融合分数、触发动作、复验结果、最终判定和各阶段时延。失败或中断的 run 也登记。

## 指标口径提醒（防止不同 run 之间不可比）

- 答案准确率用官方公开测试总题数作分母，按同一 CRAG 三档评判口径记录 Correct、Incorrect 和 Missing。另记执行与解析失败。拒答准确率使用同一标注子集的应答／应拒答标签。
- 风险为最终接纳的样本中答错的比例，覆盖率为接纳样本占比。零接纳时风险记为不适用。
- 检索与评分配置在开发集选择，阈值在校准集确定。逐题指标按官方题目 ID 配对，缺输出和拒答也计入相应分母。
- 推理延迟记录 p50/p95，包含重排序、评分和重试。在同一硬件及并发口径下比较。
