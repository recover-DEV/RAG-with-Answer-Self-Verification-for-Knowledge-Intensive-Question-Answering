# 实验台账

写论文第 5 章时，你唯一的依据就是这张表。**每次跑完一个实验，立刻加一行**，不要等到写论文时回忆。

## 填写规则

- 一行 = 一次 run（一个 `results/runs/<run_id>/`）
- 「预期」列很重要：如果实测和预期差得远，说明有 bug 或者有发现，两种都值得停下看一眼
- 失败/中断的 run 也记，标在备注里——"我试过但不行"是排除法论证的一部分，答辩时会被问

## 指标口径提醒（防止不同 run 之间不可比）

- `correct` 的判定方式必须固定：CRAG 官方三档（Correct / Missing / Incorrect），Correct=+1、Missing=0、Incorrect=−1
- 风险 = 被接受样本中答错的比例；覆盖 = 被接受样本占比；α 是预先设定的目标风险上界
- 阈值**只在 cal 集上选**，test 集只用于报告——台账里要写清"阈值选自哪个 split"
- 解析失败（JSON 抠不出来）的题记为 `correct=False, conf=0`，并在备注里单独记失败率
